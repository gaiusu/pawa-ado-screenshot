# パワアド能力データスクショつなぎ

パワプロアドベンチャーズのスクリーンショットを、端末内で切り取り・結合するブラウザ用ツールです。公開サイト：https://gaiusu.github.io/pawa-ado-screenshot/

## 1キャラの画像をつなぐ

1. 「1枚の画像を作る」タブを選びます。
2. 同じ冒険者・同じタブのスクショを2〜10枚選びます。隣り合う画像で同じ項目が1〜2段重なるように撮影してください。同じ欄から1枚ずつ追加できます。
3. 「1枚につなぐ」を押します。特殊能力・サクセスデータの重なりと上下の順番を自動で判別します。
4. 全項目と最終行を確認し、PNGを保存・共有します。必要に応じて「つなぎ目を調整」で各つなぎ目を調整できます。

重なりが不足する画像は合成せず、追加のスクショを案内します。このタブの結合機能は従来のままです。

## 6人パーティのシートを作る

1. 「6キャラをまとめる」タブを選びます。
2. 上部の自由記入欄2行に入力します（各80文字まで）。記入例は表示しません。
3. 各キャラのスクショを1枚ずつ、最大6枚選びます。スクロール途中の画像も使用できます。
4. 「パーティシートを作る」を押します。上部に2行メモ、その下に横2列×縦3段でスクショを配置します。キャラ間に番号や見出しの文字は入れません。
5. 各画像の「シート上の位置」で配置順を調整します。同じ番号を選ぶと2枚の位置が入れ替わります。チェックを外した枠は文字のない空欄になります。
6. 切り取り範囲と並び順を確認して保存・共有します。入力内容は自動でプレビューと保存画像に反映します。入力中も自由記入欄を操作できます。

6人用では特殊能力欄のスクロール前後の結合、キャラの自動分類、重複の除去を行いません。選んだ1枚につき1枠を使用し、写っている内容だけを載せます。同じ見た目のキャラや同じスクショも、別々の枠に残します。全項目を載せたい場合は、1キャラ用タブで先につないだ画像を選んでください。

横長のスクショから能力データ枠を自動で切り取ります。縦長の結合済み画像はそのまま使用します。切り取り方法の選択欄はありません。

画像の描き直し・補完・引き延ばしは行いません。切り取りは元画像の整数ピクセルの範囲を原寸でコピーします。シートは各画像を原寸で配置し、高さ上限による縮小は行いません。個別の切り取り画像も原寸で保存できます。

選択画像はタブごとに保持します。切り替え後は作成ボタンを押してプレビューを再作成してください。6人用の選択画像は3列×2段に並べ、一覧内のスクロールなしですべて表示します。読み込み後は一覧へスクロールします。1キャラ用は作成ボタンへスクロールします。

## 対応範囲と保存

- PNG・JPEG・WebP。1枚20MB、2400万画素まで。
- 1キャラ用：横向きの能力データ（特殊能力・サクセスデータ）、2〜10枚。
- 6人用：2行の自由記入欄＋1〜6枚のスクショ。自動切り取りはゲームの横向き画面の配置に合わせています。
- シート全体が6400万画素、または縦横16384pxを超える場合は作成を止めます。

「画像を共有」は対応端末の共有メニューを開きます。Xなどの共有先を選んでください。共有機能が使えない場合はPNGを保存して共有先で添付します。保存名には日付・時刻・識別子を入れます。

画像を解析サーバーへ送信する処理はありません。画像はページ内のメモリで扱い、ページを閉じると破棄します。

## ローカルで確認する

このフォルダーをHTTPサーバーで配信します。例えばPythonがある環境では `python -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000/` を開きます。HTMLのダブルクリックではブラウザの制限でJavaScriptモジュールを読み込めません。

実画像6枚の採用・原寸切り取り・2列3段への配置、1枚だけの配置、同じ画像の別枠への配置、位置の入れ替え、自由記入欄の自動反映、原寸保存、通常の1キャラ結合をブラウザで確認しています。スマホ相当の表示幅で確認していますが、実機スマホでの確認は未実施です。

## ファイル構成

- `index.html`：画面と説明文
- `style.css`：表示・スマホ向けレイアウト
- `app.js`：選択・タブ・配置操作・保存・共有
- `core.js`：1キャラ用の位置合わせ・結合
- `batch.js`：原寸の切り取り・パーティシートの作成

ビルド・追加ライブラリ・APIキーは不要です。相対パスを使い、GitHub Pagesのサブディレクトリにも対応します。公開する場合はこのフォルダーのファイルと `.nojekyll` を配置してください。

本ツールは非公式です。
