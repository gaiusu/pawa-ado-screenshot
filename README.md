# パワアド能力データスクショつなぎ

パワプロアドベンチャーズの能力データの、スクロールした複数のスクリーンショットを1枚にまとめるブラウザ用ツールです。

## 使い方

1. 同じ冒険者・同じタブのスクショを、一覧の上から下まで撮影します。隣り合う画像で同じ項目が1〜2段重なるようにしてください。
2. 「スクショをまとめて選ぶ」で2〜10枚を選びます。同じ欄から1枚ずつ追加することもできます。
3. 「1枚につなぐ」を押します。画像の重なりから上下の順番を自動で判別します。
4. すべての項目と最終行が入っていることを確認し、PNGを保存するか「画像を共有」を押します。

選択済み画像は個別に削除できます。同じ位置の画像は重複として案内します。すべての画像をつなぐ重なりが見つからない場合は合成せず、途中のスクショの追加を案内します。

スマホ表示では、2枚以上の画像を読み込むと「1枚につなぐ」ボタンへ自動スクロールします。つなぎ目が少しずれる場合は、「つなぎ目を調整」で対象のつなぎ目を選び、個別に調整できます。

## 対応範囲

- 横向きの「能力データ」のサクセス能力（特殊能力一覧）・サクセスデータ。
- PNG・JPEG・WebP。1枚20MB、2400万画素まで。
- 1回につき同じ画面のスクリーンショット2〜10枚。
- 画面レイアウトが違う場合や、重なりのない画像には未対応です。

文字や数値を生成し直さず、画像の重なりを比較して切り貼りします。画像を解析サーバーへ送信する処理はありません。選択画像はページ内のメモリで扱い、ページを閉じると破棄されます。

## 画像の共有

合成後の「画像を共有」から、対応端末の共有メニューを開けます。Xなどの共有先を選択してください。共有機能が使えない場合は「PNGを保存」から保存し、共有先のアプリで添付してください。

## GitHub Pagesでの公開

このフォルダーのファイルをリポジトリのルートに配置します。GitHubの Settings → Pages で、Source を「Deploy from a branch」、Branch を「main」、フォルダーを「/ (root)」に設定します。

ビルド、追加ライブラリ、APIキーは不要です。`.nojekyll` はそのまま残してください。GitHub Pagesのサブディレクトリでも動く相対パスを使用しています。

## 更新する場合

- `index.html`: 画面の構成・説明文
- `style.css`: 表示・スマホ向けレイアウト
- `app.js`: 画像選択・保存・共有
- `core.js`: 画像の位置合わせ・合成

管理用メタデータ、ログイン情報、利用者のスクリーンショットをリポジトリに追加する必要はありません。

本ツールは非公式です。
