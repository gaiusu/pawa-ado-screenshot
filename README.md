# パワアド能力データスクショつなぎ

パワプロアドベンチャーズの能力データの、スクロール前後のスクリーンショットを1枚にまとめるブラウザ用ツールです。

## 使い方

1. 「スクロール前の画面」に、一覧をいちばん上に戻した画像を選びます。
2. 「スクロール後の画面」に、一覧をいちばん下まで動かした画像を選びます。
3. 「1枚につなぐ」を押します。
4. 最終行まで含まれていることを確認して、PNGを保存します。

前後の画像は、同じ項目が1〜2段重なるように撮影してください。それぞれの画像を個別に選び直せます。自動位置が少しずれる場合は、つなぎ目を手動調整できます。

## 対応範囲

- 横向きの「能力データ」のサクセス能力（特殊能力一覧）・サクセスデータ。
- PNG・JPEG・WebP。1枚20MB、2400万画素まで。
- 1回につき同じ画面のスクリーンショット2枚。
- 画面レイアウトが違う場合や、重なりのない画像には未対応です。

文字や数値を生成し直さず、画像の重なりを比較して切り貼りします。画像を解析サーバーへ送信する処理はありません。選択画像はページ内のメモリで扱い、ページを閉じると破棄されます。

## Xへの共有

合成後の「Xで共有」から、対応端末の共有メニューを開けます。共有先にXがある場合は選択してください。共有機能が使えない場合は、画像を保存してXの投稿画面で添付してください。Web版の投稿画面には画像は自動添付されません。

## GitHub Pagesでの公開

このフォルダーのファイルをリポジトリのルートに配置します。GitHubの Settings → Pages で、Source を「Deploy from a branch」、Branch を「main」、フォルダーを「/ (root)」に設定します。

ビルド、追加ライブラリ、APIキーは不要です。`.nojekyll` はそのまま残してください。GitHub Pagesのサブディレクトリでも動く相対パスを使用しています。

## 更新する場合

- `index.html`: 画面の構成・説明文
- `style.css`: 表示・スマホ向けレイアウト
- `app.js`: 画像選択・保存・共有
- `core.js`: 画像の位置合わせ・合成

管理用メタデータ、ログイン情報、利用者のスクリーンショットをリポジトリに追加する必要はありません。

本ツールは非公式です。
